## 一、核心产业框架 / 方法论（新增于"复盘观察直播"之外的体系）

> 复盘观察直播语料里，产业框架多为"盘面情绪 + 板块拆解"；会员课则上升到**产业路线 + 估值分层 + 交易闭环**的授课结构。

### 1.1 篇一：Rubin 光互联三大展望框架〔归纳〕

马老师将 Rubin 升级带来的机会拆成三条互联层级 + 一条时间轴：

1. **技术路线确认 vs 业绩兑现的时间错配**：NPO/CPO/OCS 目前"技术路线落地了，不代表可以大规模放业绩"，对应上市公司业绩兑现"至少是 28 年到 30 年维度"。
   - 〔原话〕"无论是 NPO CPO OCS，它只是告诉你这条技术路线落地了……正常来讲，它是 28 年的事……它没有业绩的，在今年没有业绩，明年也没有业绩。"
2. **互联三层（UP / OUT / CROSS）**〔待核实：术语来源，疑似中信证券报告的框架〕：
   - UP = 机柜内连接；OUT = 机柜与机柜之间互联；CROSS = 超节点与超节点之间互联。
   - 〔原话〕"到了这个 cross 的，就相当于说这个超节点和这个超节点……那只能是光纤，理论上来说最好是空心光纤。"
3. **NPO/光互联的驱动力**：HBM 高速带宽存储"太贵+没货"，倒逼英伟达/谷歌在机柜内增加光的比重做架构调整。
   - 〔原话〕"机柜内的光交换机是因为 HBM 的高速带宽存储太贵了……所以我现在只能通过机柜内增加光的这个使用比重，来帮我把速度加快。"
4. **产业链卡位**：光芯片（磷化铟激光器、硅光芯片）、电芯片、薄膜铌酸锂（ASR 误转"薄膜磷酸锂"）、保偏光纤、空心光纤、FAU/可拆卸 FAU、CW 光源等上游环节确定性 > 下游。
5. **往往被市场情绪错杀**：基本面没坏但市场用脚投票，形成"灯下黑"（见术语表）。

### 1.2 篇一：真实账户"极限解套"案例方法论〔归纳〕

> 这是篇一的核心教学内容——用一位真实会员的账户演示"被深套 50%~60% 后如何自救"。本篇只提取可复用的方法论步骤，不转述具体涨跌幅数值。

方法论五步〔归纳，每一步都有原话支撑〕：

1. **先定反弹大框架**（8 月 2 日"科技和老登和解"四方向框架）→ 圈定"科技 + 小市值 + 核心位置 + 有业绩预期"的标的池。
2. **超跌反弹以小为主 + 核心壁垒**：〔原话〕"快速超跌反弹以小为主，同时具备核心壁垒的它的弹性会更大。"
3. **涨停基因辨识度**：〔原话〕"涨停基因也就代表说它这个标的很容易被激活……在短线资金层面上，它是进入过他们的观测视野范围的……它具备了辨识度。"
4. **去弱留强（而非去强留弱）**：〔原话〕"大部分人是去强留弱……实际上是应该倒过来叫去弱留强。"
5. **进退自如的仓位**：解套时保留部分现金 + 关键时点补仓，而非一次性重仓。

### 1.3 篇一："科技和老登和解"四方向框架（8 月 2 日加播，全文反复引用）〔归纳〕

〔原话〕"我们认为下半年整个市场大概率是科技和老登轮番上阵……它是一个全面和解的这种走势。"

四大方向（按确定性排序）：
1. **业绩驱动**（确定性最高）：海外链、非银金融（券商保险）、出海制造（白电/摩托/扫地机/工程机械）。
2. **业绩预期驱动**：国产替代（半导体测试、先进封装、CPU/GPU 国产算力）。
3. **AI+消费 / 端侧 AI**：苹果 AI 手机、英伟达 AI PC、机器人"情感陪护/玩偶/机器狗"形态。
4. **能源安全**：储能、锂、电解液（中长期逻辑，但缺乏资金共振）。
5. 另附时间节点催化项：商业航天（SpaceX 对标、朱雀发射）、机器人。

### 1.4 篇二：上半年思路 + 至暗时刻复盘框架〔归纳〕

核心框架是**"发现机会 → 找确定性 → 找问题点 → 做对应应对"**四段论：
〔原话〕"一个投资的发现机会，然后找到里面的确定性，然后找到里面的问题点，做对应的应对。"

配套两大支撑：
1. **聚焦单一主线**：〔原话〕"上半年我们的思路非常简单，简单到令人发指，就是……聚焦，聚焦再聚焦。"（只做科技 AI 主线，其余"都是杂毛"）。
2. **6 月 22 日锚点复盘法**：以大阳线当天为锚点，回看"科技带情绪 → 拉权重补量"的进攻节奏是否成立；一旦出现"硬拉权重、科技不共振、十字星、放量阴线"等瑕疵/弱势信号，就是降仓位时点。
   - 〔原话〕"你冲关去拉权重没毛病，但是你要遵循一个节奏……科技性带情绪，情绪恢复得差不多的时候，拉权重，补量。"

### 1.5 篇二：WAIC 2026 前瞻框架〔归纳〕

1. **华为升腾超节点为主线催化**：950 真机亮相→今年小规模/四季度放量→明年 960 大规模放量→后年 970。
   - 〔原话〕"华为的 950 这个东西出来，是支撑你现在所有国产替代能够量产放量、业绩不断超预期……你就靠这个东西支撑。"
2. **机器人五阶段论**（对应自动驾驶 L1–L5）：L1 对外部刺激反应 → L2 强化学习 → L3 想象中模拟学习 → L4（?）→ L5 从他人想象/语义中学习。
   - 〔原话〕"我们看到的机器人的学习的五阶段……对应的是自动驾驶的五个阶段 L1 L2 L3 L4 L5。"
   - 核心判断：机器人数据积累极慢，两三年内难找好股票，只能当题材。
3. **存储国产替代**：长鑫/长存（ASR 误转"长兴/长春"）卡位 + 推理侧硬盘需求 + "涨价+扩产"双逻辑。
4. **智能体傻瓜化 → token 用量抬升 → 算力租赁水涨船高**。

## 三、纪律体系（反复强调，附原话）

> 会员课纪律密度远高于复盘直播，主题从"别追涨/分批/贴均线"升级到"知行合一 + 认知救赎"。

1. **七周均线 = 最后防线，破位无条件回避，不赌"万一"**
   - 〔原话〕"破了七周均线，不管什么原因，你都应该做对应的回避，而不应该考虑万一明天涨了怎么办？"
   - 〔原话〕"七周均线作为我们的防御的最后一道防线。"
2. **做交易要像无情机器，抛掉情绪**
   - 〔原话〕"做交易就应该像一个无情的人一样，就是一个没有感情的操作机器……你但凡有一点点个人的情绪掺杂在里面，你的判断就会失去它的一个准确度。"
3. **去弱留强，而非去强留弱**
   - 〔原话〕"实际上应该是倒过来叫去弱留强……我们只做强，不做弱，不做超跌反弹，也不做补涨。"（补涨前提：热度能持续）
4. **老股民死在抄底上，只赚确定性的钱**
   - 〔原话〕"老股民是死在抄底上……你要赚的是确定性，你其实应该做的是确定性的东西，而不应该做更多的感性上的东西。"
5. **一旦错过介入点，不再强求**
   - 〔原话〕"你一旦错过了，就不要再强求了……没有必要重新等待下一次机会。"（其"反转三兄弟"课程里的原则）
6. **仓位进退自如，不拉满也不压太低**
   - 〔原话〕"不要太低……机会来的时候是不敢上仓位的，太高的情况下，你又会很被动。"
7. **知行合一 vs 财富代码无用**
   - 〔原话〕"同样的财富代码，在不同的人的手中，有的人能赚一倍……有人能亏 50%，同样的标的……财富代码有什么用？没有用。"
   - 〔原话〕"命运掌握在你自己手上，不是掌握在我这里。"
8. **买熟人、看得懂的行业，抗住耳边风**
   - 〔原话〕"为什么建议大家聚焦……因为只有这样子，你对这个行业板块的认知才不会因为别人的轻易的一句话……而发生比较大的改变。"
9. **量价齐升是唯一健康形态，出现异常即紧张**
   - 〔原话〕"凡是不是量价齐升的，对我们来说都是异常现象，需要紧张的时刻。"
10. **反转三兄弟不是为了赚大钱，是先保命**
    - 〔原话〕"不是说反转三兄弟一定让你赚大钱，而是要先把你的命保下来，你只有命保下来，你才能赚钱。"

## 四、表达 DNA 增量（会员课 特有 / 与复盘直播的异同）

### 4.1 与复盘观察直播"口播体"的相同点（继承）

- 开场"有声音的话帮我扣一个一"（≈复盘直播"声音正常吗扣一"）。
- 高频语气词/断句节拍：对吧、好吧、我们说、也就是说、那么（与复盘一致）。
- 条件式+概率表达内核未变：〔原话〕"大概率不会……""正常来讲，它是 28 年的事。"

## 五、新的心智模型 / 决策启发式（现有 5 模型 8 启发式之外）

> 以下为相对明确的**新增候选**，建议与 skill 现有 5 模型/8 启发式清单比对后并入。

1. **极致抱团崩塌模型**〔归纳，篇二核心〕：
   主线抱团必然走到极致 → 靠增量资金/杠杆维持 → 增量一旦断流即崩塌 → 一直跌到击穿所有杠杆成本（爆仓）→ 才迎来大反转。
   〔原话〕"不打到绝望，不打到爆仓，不打到你最后一个子弹没有，它是绝对不会反弹的。""极致抱团之后，流动性已经干涸……大家就是比谁跑得快。"（可视为"聚焦主线"的反向风险认知，补齐了"抱团上涨"到"抱团崩溃"的完整周期。）
2. **涨停基因 / 辨识度选股启发式**〔归纳，篇一〕：
   反弹自救第一步"选谁"= 近期出现过涨停（=短线资金视野内的辨识度）+ 小市值 + 核心壁垒 + 主线赛道。**〔他说过的〕**"涨停不能太远，必须是在最近一段时间出现过涨停，出现在那些短线资金的眼睛中。"
3. **去强留弱 → 去弱留强 的反向纠正**〔归纳〕：
   多数人"解套一个补仓一个弱的"，正确是"砍弱标、把仓位集中到最强标的"。**〔他说过的〕**"大部分人是去强留弱……实际上应该是倒过来叫去弱留强。"
4. **确定性的钱 vs 感性的钱**〔归纳〕：
   交易前置筛选标准——只要"确定性"（能不能被证伪、能不能看到业绩/订单），不要"感性/万一"。**〔他说过的〕**"没必要去赚抄底的钱，你要赚的是确定性。"
5. **进退自如仓位启发式**〔归纳〕：
   仓位管理目标不是"满仓搏"，而是保证"机会来时敢上、风险来时敢撤"。
6. **涨价+扩产双逻辑启发式**〔归纳，篇二〕：
   产业周期选股要找"量价齐升"（既能扩产又能维持/提升价格），而非单纯的扩产逻辑或单纯的涨价逻辑。

## 六、待核实清单（宁缺毋滥）

- **UP / OUT / CROSS** 三层的准确术语来源（疑似中信证券 Rubin 报告框架，非马老师原创，需核对原文）。
- **NVL576 托盘"九+18+九"** 的精确数字（ASR 混乱，原文"十加98调整为九加18加九，中间加了一倍"）。
- **"scot / scott"**（篇一东方证券报告环节）：马老师说"他把这个 scot 放在保偏光纤前面"，并解释其功能为"把激光发射器放远端、中间加一个转换"——疑似某种光互联/光转换模块，具体中文名与英文全称待核实。
- **"micc / micp"**：篇一提到"讲一下 micc""很多 micp 的 PCB 公司"，疑似 mSAP 或某 PCB 工艺/MLCC 的误转，待核实。
- **"covers l / coversle"（台积电）**：疑似 CoWoS-L 或 CoWoS 相关键合技术，待核实。
- **七周均线 vs 七天均线**：篇二同时出现"七周均线作为最后止损位"与"回到七天均线"（"7 日均线"），需确认是两条均线（7 日=短线、7 周=中线最后防线）还是 ASR 混淆。
- **"老登"精确所指**：本篇延续"老登=低位权重/传统蓝筹"用法，与 part1 术语表一致，但会员课更多用"科技和老登和解"的框架表述，含义无新增。
