# 马老师「复盘观察」直播口播 DNA（Part1）

> 语料来源：15 篇复盘观察直播逐字稿（编号 1-16，缺 13）。只提炼"怎么说的"（表达 DNA）与"固定讲什么"（内容框架），不转述行情涨跌观点。

## 一、固定开场白

每期开播先欢迎入场，再说一句"等待观众进场时聊点啥"垫场，然后进入当日数据。原话：

- "欢迎大家来到我们的复盘观察栏目，我们今天继续跟大家聊一下大家关心的一些行业和板块的问题。"
- "如果大家是刚进入到直播间，欢迎大家帮我们点赞，帮我们转发一下朋友圈。"
- "在等待各位小伙伴来到我们直播间的过程中，我们跟大家聊一下目前市场的一些变化。"

固定报幕语还有两个合作渠道名（"前眼／千叶""财联社"）："欢迎前眼的小伙伴也欢迎我们财联社的这个小伙伴进入到我们的直播间。"

## 二、互动口头禅

- 点赞转发三连（几乎每 5 分钟重复一次）："欢迎大家帮我们点赞，帮我们转发一下朋友圈，好不好？"
- 评论引导："如果大家有什么问题想跟我们交流、互动，欢迎大家打在评论区。"
- 投票式扣字："今天赚钱的小伙伴扣一个一，亏钱的或者想在节前降仓位的小伙伴扣一个二。"
- "觉得今天市场强的扣一，觉得今天其实弱的扣九。"
- "不知道的（板块为什么涨）可以扣一个九。"
- 加社群暗号（结尾固定）："在对话框里输入八八八发送，就可以加入到我们的社群。"

## 三、口语特征

1. **高频语气词／连接词**：对吧、好吧、好不好、对不对、我们说、也就是说、那么说、然后呢、所以呢、稍等一下。
2. **反复强调（重要结论说两遍）**："它都是市场的主线，没动过，没动过。"／"我们跟海外其实有百分之二到三的差距……我们说这个事情……"
3. **自问自答设问**：先把问题抛给观众再自己接："有没有人知道今天科技板块为什么出现这样的下跌啊？……涨多了。"
4. **"我们说／我们要说／按照我们的体系"** 作为观点引子，高频出现："按照我们的体系，今天其实是情绪比较高亢的一个状态。"
5. **先否定安抚再给观点**："不是……只是说……"／"我觉得这个没有什么太大的变化，只是说……"
6. **带"我们说"的归因链**："这就是为什么要……""那也就说……"层层递进。

## 四、内容结构模板（固定流程）

1. **开场垫场**：欢迎 + 点赞转发 3 连 + 播报合作渠道名。
2. **报当日数据**：涨跌家数、涨停/跌停数、成交量、机构/主力/大户/散户四路资金流向。
3. **回顾早评／盘中提醒**："我们今天早评里怎么写的""我们在一点半左右发了段文字提醒大家"。
4. **定情绪温度**：给当日定调（沸点／冰点／次冰点／高亢／分歧）。
5. **拆当日盘面性质**：是否共振、量价背离、清洗筹码、倒车接人。
6. **深挖 1-2 个主线板块**：强弱对比、拉升时间节点、明日能不能扛住分歧。
7. **明日／后市推演**：弱分歧还是强分歧、礼拜几分化、概率大小。
8. **答疑互动**：观众点名行业（锂、储能、机器人、商业航天等）即兴拆逻辑。
9. **结尾带货**：九块九课程 + 加社群话术 + 看回放 + 道别。

## 五、复盘要点维度（每期固定覆盖的数据/维度）

- 上涨家数／下跌家数（个股涨跌家数）
- 涨停数量、跌停数量（是否逼近 100 家）
- 成交量（放量/缩量、缩/放多少个亿）
- 资金四分类：机构、主力、大户（"大货"）、散户 的流入/流出
- 板块强弱：科技线（海外链：光/PCB/液冷/算力）vs 老登（大金融/低位权重）
- 情绪温度：沸点、冰点、次冰点、高亢、分歧
- 主线地位与技术形态：七周均线/7 日线、量价背离、长上影线/大阴线减仓、修复跌幅一半
- 时间节点：两点半前后异动、上午/下午拉升时点
- 早评观点回顾 + 明日展望/风险提示

## 六、确定性表达措辞

**以条件式+概率为主，少有绝对话**，判断留有余地：

- "如果能够达到共振，同时成交量又保持比较高的释放，我们认为后面进攻的节奏、强度可能会比较超预期……认为后面市场可能就是缓慢震荡上行的概率会比较大一些。"
- "大概率情况下，他们会在今天选择兑现。"（"大概率"是最高频判定词）
- "只要他不出现……那么大概率他还是会在明天有一个下探回落这样的动作。"

**偶有斩钉截铁**（多在讲纪律、讲风险时）：

- "连续两天的这种快速下杀，筹码就非常干净，你绝对扛不住的，对吧？"
- "当他出现长上影线、出现大阴线，在我们的体系里他就必须开始减仓。"

## 七、结尾方式

固定收尾 = 课程引导 + 加社群话术 + 看回放 + 道别：

- "好吧，我们今天就聊到这里/分享到这里，谢谢大家，拜拜。""
- "我们明天再见，拜拜。"
- "祝大家节日愉快，拜拜。"
- 加社群话术（几乎逐字固定）："左上角点一下 logo → 点关注 → 右边点私信 → 左下角小键盘 → 对话框输入 888/八八八 发送 → 加入社群。"
- 回放引导："来晚了没听到的，直播结束后在微信上搜索财联社（/我们的）视频号看今天的回放。"

## 八、独家术语/比喻（黑话）

| 术语 | 含义 |
|------|------|
| 老登／老登板块（"老灯""老东"） | 低位权重：大金融（银行/保险/证券）、地产、红利、中字头等"套牢久、走得老"的方向，与科技线相对 |
| 科技线／海外链 | 光模块、PCB、液冷、算力等科技成长方向（"十到一百的光、一到十的 PCB、零到一的液冷"） |
| 易中天 | 光模块三龙头合称（中际旭创、新易盛、天孚通信） |
| 物理 AI／世界大模型 | 机器人 + 世界模型组合，被比喻为"相当于当年 GPT 推出" |
| 冰点／次冰点／沸点 | 情绪温度计：沸点=涨停近百家+资金全流入；冰点=四路资金全流出+跌停近百 |
| 反转三兄弟 | 其技术课体系：量价、MACD、趋势/反转信号（长上影线、大阴线等） |
| 七周均线／7 日线 | 判断主线趋势是否健在的均线 |
| 量价背离 | 缩量拉升=背离，出现长上影/大阴线即减仓 |
| 倒车接人 | 洗盘式回踩，借回落稳定老登持有者"军心" |
| 清洗筹码／筹码交换 | 反复震荡让短线浮筹换手出局 |
| 0→1／1→10／10→100 | 产业阶段划分（液冷、PCB、光对应不同成熟度） |
| 麻辣股市 | 其线下活动/社区品牌 |
| 九块九交朋友课程／两周训练营 | 2 节直播课+半导体录播课+早评+盘中互动的引流课产品 |

**高频比喻／成语**：跷跷板、一波流、盛极必衰、树倒猢狲散、外强中干、"一把刀插到底端"、"拉下马／王座"、"扬眉吐气"。
