## 这是什么

马老师（公众号「谈笑间228」作者）有两套内容：**「每日笔记」文字盘后文章**（写作体）和**「复盘观察」直播**（口播体）。本项目专门还原**直播口播**这一套——不是文章仿写、不是角色扮演，而是能陪你复盘市场、聊思路、安抚情绪的直播口播文案。

本项目由 [女娲 · 思维蒸馏](https://github.com/alchaincyf/nuwa-skill) 基于 31 篇「复盘观察」直播逐字稿蒸馏生成，与「谈笑间228视角」技能（公众号写作体 + 交易分析工具包）形成互补。

## 能力

- **复盘口播文案**：输入当日盘面 / 板块 / 个股话题，输出 500–2000 字口播稿（默认约 1000 字）
- **三塔模型**
  - **A塔·投资思维**：继承谈笑间228 的 5 个心智模型（分歧-修复、共振、量化时代跟随、条件分支、预期差）+ 8 条决策启发式
  - **B塔·复盘表达**：直播独有语言 DNA——开场三件套、扣数字问卷、对吧节拍、7 步复盘结构、条件式措辞
  - **C塔·陪伴感**：用「我们」视角安抚亏损、降温亢奋、拉近距离
- **直播体 vs 写作体区分**：只还原直播口播风格，不硬塞公众号笔记黑话（达芬奇/柚子等）
- **合规内置**：不点买卖点、不荐股、不承诺收益、不冒用身份带货

本仓库是**平台无关的通用 Skill 包**，任何支持读取文件系统的 Agent 都能调用：

Agent 读取 `SKILL.md`（自包含，含 YAML frontmatter 触发条件）即可获得全部能力。完整安装协议见 [INSTALL.md](./INSTALL.md)。

在「我的技能」中搜索「**马老师口播文案**」，或手动导入本仓库 ZIP（`SKILL.md` + `references/`）。
