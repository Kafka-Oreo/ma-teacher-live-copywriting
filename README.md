## 这是什么

马老师（公众号「谈笑间228」作者）有三套内容：**「每日笔记」文字盘后文章**（写作体）、**「复盘观察」直播**（复盘陪伴口播体）、**「会员课」**（教学口播体）。本项目专门还原**口播**这两套——不是文章仿写、不是角色扮演，而是：

- **复盘陪伴口播**：陪你复盘市场、聊思路、安抚情绪
- **会员课教学口播**：像上课一样拆产业链、讲方法论、系统讲交易纪律

本项目由 [女娲 · 思维蒸馏](https://github.com/alchaincyf/nuwa-skill) 基于 31 篇「复盘观察」直播 + 8 篇「会员课」逐字稿蒸馏生成，与「谈笑间228视角」技能（公众号写作体 + 交易分析工具包）形成互补。

## 训练语料

本项目基于 **39 篇马老师逐字稿**蒸馏而来。原始 ASR 转写语料合计约 **94 万中文字符**（含标点、数字、英文约 **108 万字符**，3.02 MB），剔除时间戳、说话人标记、背景音乐歌词等噪声后，有效讲课内容约 9 成。

| 语料来源 | 篇数 | 中文字符 |
|---------|------|---------|
| 复盘观察直播 | 31 篇（编号 1–33，缺 13、24） | 69.4 万 |
| 会员课 | 8 篇 | 24.3 万 |
| **合计** | **39 篇** | **93.7 万** |

**复盘观察直播（31 篇）**：每日盘后复盘逐字稿，覆盖当日盘面复盘、板块轮动拆解、连板梯队、资金流向、明日展望、与观众互动提问。这是「复盘陪伴体」的核心语料。

**会员课（8 篇）**：教学型逐字稿，深度拆产业链与交易方法论：

1. 主线的生命周期与算力租赁简析
2. Coding 之后的下一个 AI 应用场景
3. Rubin 的三大展望——机柜化、PCB、光互联
4. WAIC 大会前瞻及上半年思路回顾
5. 纯血韬定律与 Groq 3 LPX 的共振
6. 打造国际一流券商及 CPU 行业更新
7. 厄尔尼诺气候下的投资机会
8. 为什么纪律是第一位及 WAIC2026 释放了哪些产业信号

覆盖 8 条产业框架（算力租赁 / 光互联 / 芯片 / 券商 / CPU / 气候投资等）+ 完整交易纪律体系（交易系统三匹配、海龟交易法、快慢钱定位、天量警钟、底线锚定等），是「上课体」的核心语料。

## 能力

- **复盘口播文案**：输入当日盘面 / 板块 / 个股话题，输出 500–2000 字口播稿（默认约 1000 字）
- **会员课教学文案**：输入产业链 / 方法论 / 纪律话题，输出"上课体"口播稿（拆框架 → 引研报 → 讲案例 → 系统讲纪律）
- **三塔模型**
  - **A塔·投资思维**：5 个直播心智模型 + 会员课新增 5 模型（极致抱团生命周期、价值投机、卖水人卡位、等大腿、交易系统三匹配）+ 14 条决策启发式
  - **B塔·复盘表达**：直播语言 DNA（开场三件套、扣数字问卷、对吧节拍、7 步复盘、条件式措辞）+ 会员课"上课体"外壳（格言定调、引研报引书、案例对标、布置作业）
  - **C塔·陪伴感**：用「我们」视角安抚亏损、降温亢奋、拉近距离
- **会员课产业框架库**：主线生命周期、算力租赁、Rubin 光互联、WAIC 前瞻、纯血鸿蒙+Groq、券商+CPU、厄尔尼诺等 8 条产业框架
- **会员课纪律体系**：交易系统三匹配、海龟交易法、快慢钱/斩立决、天量警钟、底线锚定、去弱留强等可复用纪律台词库
- **直播体 vs 写作体区分**：只还原口播风格，不硬塞公众号笔记黑话（达芬奇/柚子等）
- **合规内置**：不点买卖点、不荐股、不承诺收益、不冒用身份带货
